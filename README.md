# My Github Assignment

***Explain version control:**
Version control is like a save system for your project. It keeps track of all changes you make and lets you go back in time and fix errors if needed.

***Explain the difference between Git and Github:**
Git is a computer program that tracks changes made on your computer, while Github is the cloud service that allows you to store and share those changes online.

***List 3 other Github alternatives:**

1. GitLab
2. Bitbucket
3. SourceForge

***Explain the difference between git fetch and git pull:**
`git fetch` - Check if there are changes online, but doesn't change your files
`git pull` - get the changes made online and updates your files

***Explain git rebase and the command for it in simple terms:**
Rebase - move your work to the latest version so your history appears clean
Command: `git rebase main`

***Explain git cherry-pick and the command for it in simple terms:**
Cherry-pick - pick one specific change from another branch
Command: `git cherry-pick <commit-hash>`
